1. 安装 Docker

1.1 更新系统

首先确保系统是最新的：

sudo yum update -y

1.2 安装必要的依赖

安装一些必要的依赖包：

sudo yum install -y yum-utils device-mapper-persistent-data lvm2

1.3 添加 Docker 官方仓库

为了加速下载，建议使用国内的镜像源，比如阿里云提供的 Docker 仓库。

sudo yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

1.4 安装 Docker

安装 Docker CE（社区版）：

sudo yum install -y docker-ce docker-ce-cli containerd.io

1.5 启动并设置 Docker 开机自启

启动 Docker 服务并设置为开机自启：

sudo systemctl start docker
sudo systemctl enable docker

1.6 验证 Docker 安装

运行以下命令，检查 Docker 是否安装成功：

docker --version

输出示例：

Docker version 20.10.24, build 590d510

如果看到“docker: Error response from daemon: Get “https://registry-1.docker.io/v2/":” ，则需要配置docker镜像源

2. 安装 Docker Compose

检查docker是否存在内置docker compose，若存在则无需再次安装docker-compose

2.1 下载 Docker Compose

从官方 GitHub 仓库下载 Docker Compose：

sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

2.2 赋予可执行权限

为下载的 Docker Compose 文件赋予可执行权限：

bash

sudo chmod +x /usr/local/bin/docker-compose

2.3 验证 Docker Compose 安装

运行以下命令，检查 Docker Compose 是否安装成功：

bash

docker-compose --version

输出示例：

markdown

Docker Compose version v2.20.2

注意：从 Docker Compose v2 开始，docker-compose 已被集成到 Docker CLI 中，因此也可以直接使用 docker compose 命令。

3. 配置 Docker 镜像加速（可选）

为了加快 Docker 镜像的下载速度，可以配置国内的镜像加速器，例如阿里云或网易云。

3.1 创建或编辑 Docker 配置文件

编辑 /etc/docker/daemon.json 文件（如果文件不存在则创建）：

bash

sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": ["https://<你的镜像加速器地址>"]
}
EOF

将 <你的镜像加速器地址> 替换为实际的加速器地址，例如：

  • 阿里云：https://<你的阿里云镜像加速器ID>.mirror.aliyuncs.com
  • 网易云：https://hub-mirror.c.163.com

3.2 重启 Docker 服务

bash

sudo systemctl daemon-reload
sudo systemctl restart docker

4. 测试 Docker 和 Docker Compose

4.1 测试 Docker

运行一个简单的测试容器：

bash

sudo docker run hello-world

如果看到 “Hello from Docker!” 的消息，说明 Docker 安装成功。

4.2 测试 Docker Compose

创建一个简单的 docker-compose.yml 文件：

bash

mkdir ~/docker-test
cd ~/docker-test
cat <<EOF > docker-compose.yml
version: '3'
services:
  web:
    image: nginx
    ports:
      - "8080:80"
EOF

运行以下命令启动服务：

bash

docker-compose up -d

然后在浏览器中访问 http://<你的服务器IP>:8080，如果看到 Nginx 的默认页面，说明 Docker Compose 安装成功。
