Python的私有属性

在 Python 中，私有属性（Private Attributes） 是一种用于限制类外部直接访问对象内部数据的机制。Python 通过名称改写（Name Mangling） 实现私有属性，并非严格的访问控制。

名称改写（Name Mangling）

Python 并不是真正隐藏了私有属性，而是将其重命名为. “_ 类名__属性名” ：

@property

在 Python 中，@property 和 @属性名.setter 是 装饰器（Decorator） 的一种用法，用于实现类似其他语言（如 Java/C#）中的 封装（Encapsulation），即对类的属性进行更精细的控制：比如限制赋值范围、自动计算属性值等。

@property 将一个方法“伪装”成属性，使得你可以像访问属性一样调用它，而不需要使用括号 ()。

@属性名.setter 是为通过 @property 定义的属性添加赋值逻辑控制，允许你在设置属性值时执行自定义验证或处理。

受保护的属性

在 Python 中，受保护的属性（Protected Attributes） 是一种约定性的访问控制方式，用于表示某个属性或方法仅供类本身及其子类访问，而不建议外部直接访问。
